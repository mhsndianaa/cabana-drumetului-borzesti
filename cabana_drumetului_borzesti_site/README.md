
# Cabana Drumețului Borzești - Site static (exemplu)

Fișiere generate pentru un site static simplu:
- index.html
- about.html
- blog/index.html
- blog/post1.html
- css/style.css
- images/logo-placeholder.png (înlocuiți cu logo-ul vostru)
- images/hero-placeholder.jpg (înlocuiți cu o fotografie reală)

**Cum îl publici:**
1. Schimbați imaginile placeholder cu fotografiile voastre în folderul `images`.
2. Modificați datele de contact din `index.html` (telefon, email, adresă).
3. Puteți publica pe GitHub Pages (repo public) sau pe orice hosting (FTP).
   - Pentru GitHub Pages: creați un repo, încărcați conținutul din acest zip și activați Pages din setări.
4. Pentru un formular de contact funcțional, folosiți un serviciu (ex: Formspree, Netlify Forms) sau implementați un backend simplu.

Dacă doriți pot adapta designul, crea mai multe postări în blog sau să adaug un formular de rezervare funcțional.
